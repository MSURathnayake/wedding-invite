Put your background music here and name it:  wedding.mp3

Use a song you have the right to use (your own recording, a royalty-free track, or a licensed one).
Keep the file under ~5 MB so it loads quickly on mobile data.
If you use a different file name, change `music.src` in src/config/wedding.js.
If the file is missing, the site still works and the music button is simply hidden.
